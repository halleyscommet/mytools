## Environment

Copy `.env.example` to `.env` and set `MAX_UPLOAD_BYTES` to the upload cap in bytes.
For example, `1073741824` is 1 GB and `2147483648` is 2 GB.

The yt-dlp downloader uses `ffmpeg` for format merging when needed.
